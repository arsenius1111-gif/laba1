# Информационная система театра

Автор: Арсений Ходневич  
Вариант: 27

## Описание проекта

Информационная система театра предназначена для управления спектаклями и театральными залами. Программа позволяет просматривать каталог спектаклей, добавлять новые постановки, сравнивать спектакли, управлять репертуаром залов и учитывать продажу билетов.

Проект разработан на языке C++ с использованием объектно-ориентированного программирования.

## Основные возможности

- Просмотр каталога спектаклей.
- Добавление балетов, опер и мюзиклов.
- Сравнение спектаклей по названию и длительности.
- Создание и управление театральными залами.
- Добавление и удаление спектаклей из репертуара.
- Продажа билетов с проверкой вместимости зала.
- Изменение вместимости зала.
- Просмотр полной информации о зале.
- Просмотр аналитики зала.
- Интерактивная демонстрация полиморфизма.

## Используемые технологии

- C++20.
- GCC (g++).
- Стандартная библиотека C++.
- STL-контейнер std::vector.
- Умные указатели std::shared_ptr.
