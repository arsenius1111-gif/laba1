# Система управления театром (Theater Management System)

Консольное приложение на C++ для моделирования работы театрального репертуара и управления залами. Программа позволяет вести учет спектаклей, распределять их по залами и контролировать дневные ограничения по суммарной длительности репертуара.

## Особенности и архитектура

### Классы и сущности
- Performance (Спектакль): Содержит сведения о названии, режиссёре, жанре, длительности (в минутах) и возрастном цензе.
- Hall (Зал): Хранит номер зала, его вместимость и динамическую коллекцию спектаклей (std::vector<Performance>).

### Соблюдение требований ТЗ и бизнес-логика
- Ограничения предметной области: В классе Hall реализована проверка хронометража. Суммарное время всех спектаклей в одном зале не может превышать 480 минут (8 часов) в день.
- Полная интерактивность: Иерархическое меню (MainMenu -> HallMenu -> PerformanceMenu) позволяет просматривать, добавлять и редактировать характеристики объектов в реальном времени.
- Защита от некорректного ввода: Все текстовые и числовые потоки ввода (std::cin) защищены от сбоев типов (буквы вместо чисел, некорректные диапазоны, застревание в буфере).

### Соответствие стандартам SonarQube / C++17
- Отсутствие глобальной директивы using namespace std;.
- Строгая const-корректность методов и параметров.
- Низкая когнитивная сложность (Cognitive Complexity < 10) за счёт использования switch-case и выноса операций во вспомогательные функции.
- Порядок инициализации членов класса строго соответствует порядку их объявления.
