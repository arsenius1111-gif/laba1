# Лабораторная работа по C++ — Проект "Театр"

Программный комплекс на C++20 для управления репертуаром театра, объектами спектаклей и аналитикой залов.

## Архитектура проекта

- `Performance` — класс для учета данных спектакля (название, режиссер, жанр, длительность, возрастное ограничение). Реализует перегрузку операторов сравнения (`==`, <=>`), потоковый ввод-вывод (`<<, >> через *hidden friend*) и дружественные функции.
- `Hall` — класс бизнес-логики для управления залом (вместимость, проданные билеты, список спектаклей). Реализует перегрузку операторов += (добавление спектакля с проверкой лимита времени) и -= (удаление спектакля).
